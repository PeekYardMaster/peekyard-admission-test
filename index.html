Projeto Farol

Esta página permite testar, de maneira observável, o processo de inscrição de projetos na Peekyard: envio do formulário, triagem pública, avaliação institucional consultiva e elaboração de um parecer privado para revisão humana.

Ambiente de demonstração. Este projeto não oferece serviços, não recebe inscrições próprias e não é uma publicação na vitrine Peekyard.

O que está sendo validado?

  • Uma proposta explicada com clareza, em uma página HTML pública e independente.
  • Uma origem versionada em Git e passível de verificação por commit.
  • Uma decisão humana posterior às análises automatizadas, sem aprovação implícita.

Privacidade e dependências

A página usa apenas HTML e CSS próprios e fontes do sistema. Não solicita dados pessoais, não utiliza cookies, scripts, serviços de analytics, recursos remotos ou formulários. O único link de saída é o contato público do responsável no GitHub.
